### Shell Commands

pwd : show the current directroy
cd (parameter): change directory
ls : list files and directories
/ root
. current directory
.. upper-level directory
/[directory name]: absolute path
./ " : relative path(cur)
../ " : relative path(up)
-l : show detailed imformation(long format)
-lh same as above, but size in units

[more ls command](https://linuxcommand.org/lc3_lts0030.php)

# long format
file permissions - owner - group - size(in bytes) - modification time - file name

# tip: autocompletion
Press "tab" key
# tip : past commands
Press "up arrow" key

clear : terminal clear(literally)
